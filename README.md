# 📚 More Advanced Library System With So Many Features

## 🎯 Objective

The main objective of the project is to have a system that contains all features needed in any library (School library or Public library).

## 👥 Modes

This system offers different functionalities based on the type of library.

### 🏛️ For Public Library

#### 🔐 Admin Mode

Admins have full control over the public library and can perform the following:

1.  ➕ Add new books
2.  ❌ Remove books
3.  📚 View all books
4.  🔍 Search books by (title, author, publication year)
5.  📕 View borrowed books
6.  🔢 Count total books
7.  💰 Fine per day – if return book late.
8.  🚫 If user is late to return a book, they are forbidden from entering the library for a week.
9.  ➕ Add User
10. ➖ Remove user
11. 👥 View all users
12. 🔓 Logout

#### 👤 User Mode

Users can interact with the public library and perform the following:

1.  📖 View available books
2.  📥 Borrow a book
3.  📤 Return a book
4.  🔍 Search books by (title, author, publication year)
5.  🔓 Logout
